# 视频收录与知识蒸馏手册 (Video Ingestion Guide)

## 1. 概述与设计原则
在抖音无可用字幕文件、需逐一播放视频的背景下，Horizon 提供三级收录途径：

- **方法 A: 授权音视频文件直接上传 (推荐)**
  - 支持 MP4, MP3, WAV, M4A 格式。
  - 自动提取音频并做 SHA-256 去重校验，避免重复转录产生不必要的 API 账单。
  - 直接调用 Gemini 多模态接口，实现精确中文语音转录并保留时间戳（精确到秒）。

- **方法 B: 视频链接元数据登记与浏览器辅助录音**
  - 在管理界面中登记抖音视频网址（例如 `https://www.douyin.com/video/7220000000000000001`）与视频标题。
  - 配合操作系统回环录音工具或外部录音文件批量导入。

- **方法 C: 文本转录稿/手工笔记导入 (极速模式)**
  - 用户观看视频时可直接复制、转录或记录讲话核心要点并粘贴入文本框。
  - 系统自动完成语义分块（Chunking）、原子主张（Atomic Claims）提炼并即刻刷新索引。

## 2. 自动化批处理
如需自动化处理多期视频，可将视频清单整理为 `batch_videos.json`：
```json
[
  {
    "url": "https://www.douyin.com/video/7330000000000000001",
    "title": "美债发债洪峰与银行准备金冲击",
    "audio": "./data/audio/sample1.mp3",
    "publish_date": "2026-03-01"
  }
]
```
执行命令行批量导入工具：
```bash
python scripts/import_videos.py --batch batch_videos.json
```
系统将自动按阶段执行：转录 ➔ 清洗 ➔ 提炼主张 ➔ 更新检索索引。

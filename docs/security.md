# 安全与访问控制规范 (Security & Governance)

## 1. 认证与会话安全
- **密码加盐哈希**：系统使用行业级 `bcrypt`（12 轮加盐迭代计算）存储凭证，数据库中绝不存储明文密码。
- **暴力破解防护**：基于 IP 和用户名的频率限制（5 次失败锁定 15 分钟），登录尝试被记录并审计。
- **高熵会话令牌**：会话令牌使用 32 字节密码学安全伪随机数生成（`secrets.token_hex(32)`）。

## 2. API 凭证管理
- **服务端专用调用**：所有 Gemini API 交互均在服务端执行，API Key 绝不回传浏览器。
- **零日志泄露**：系统日志引擎（`logging_config.py`）配置了敏感词自动掩码规则，捕获异常时自动擦除 API Key、密码及 Cookie 敏感字符串。
- **环境变量隔离**：敏感凭证保存在 `.env` 或云端托管平台密钥管理控制台中，`.gitignore` 严禁提交真实环境文件。

## 3. Prompt 注入防御与内容边界
- **不可信输入隔离**：转录稿与外部检索结果作为证据块注入上下文，在 System Prompt 中显式声明其为事实资料，不得覆盖系统的角色定义与安全规则。
- **杜绝命令执行**：知识提炼引擎不包含任何动态 `eval` 或代码执行通道。

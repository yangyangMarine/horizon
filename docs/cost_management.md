# 成本与额度控制规范 (Cost Management)

## 1. 成本监控指标
系统在 SQLite 中实时记录每一笔模型调用的 token 消耗与估算账单：
- **今日请求次数**（默认上限 200 次/天）
- **单次提问字数上限**（默认 10,000 字符）
- **月度预算限额**（默认 $50.00 USD，可在 `config.yaml` 或环境变量中调整）

## 2. Gemini 计费优化措施
- **语义分块与适度检索**：仅将前 Top 6~8 条高关联度的原子主张与框架注入上下文，避免将整个知识库全量塞入 Prompt 造成无谓 Token 浪费。
- **音频去重哈希**：音视频文件先计算 SHA-256 校验和，如已存在相同音频则直接复用已转录结果。
- **高效轻量推理**：核心研报推理选用 `gemini-3.8-flash`，兼具强大中文理解与极低输入/输出 Token 成本。

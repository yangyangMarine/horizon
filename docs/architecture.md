# Horizon 架构全景白皮书 (Architecture Whitepaper)

Horizon 的核心设计理念是**将专家分析资产（Knowledge Assets）与底层基础设施（LLM、向量库、前端UI、云托管商）彻底解耦**。

```
+-------------------------------------------------------------------------+
|                  Layer D: 用户界面与部署 (Streamlit & Auth)              |
|  - 响应式多端 Web UI (Desktop / Mobile)                                 |
|  - 密码加盐哈希认证 (Bcrypt + Rate Limiting 防爆破)                      |
|  - 对话持久化 (SQLite Conversations) 与 Markdown 导出                    |
|  - 视频一键收录控制台与专家知识包打包中心                                 |
+-------------------------------------------------------------------------+
                                    |
                                    v
+-------------------------------------------------------------------------+
|                  Layer B: 专家推理引擎 (MacroExpertEngine)              |
|  - 意图识别与主题分类                                                    |
|  - 混合检索调度 (FTS5 + CJK Trigram + LIKE Fallback)                    |
|  - 四级知识溯源体系 (创作者原话 / 框架 / AI推演 / 外部数据)               |
|  - 证伪条件与不确定性评估                                                |
|  - 严格不虚构原话与时间戳的防幻觉保护                                    |
+-------------------------------------------------------------------------+
                                    |
                                    v
+-------------------------------------------------------------------------+
|                  Layer C: 模型与检索适配器 (Model Adapters)             |
|  - GeminiAdapter: 基于官方 google-genai SDK 调用 gemini-3.8-flash        |
|  - MockLLMAdapter: 零成本确定性单元测试适配器                             |
|  - 可替换检索后端: SQLite FTS5 / Gemini Embeddings                       |
+-------------------------------------------------------------------------+
                                    |
                                    v
+-------------------------------------------------------------------------+
|                  Layer A: 便携式专家知识包 (Expert Package)              |
|  - 纯文本 Markdown 框架体系 (frameworks/*.md)                            |
|  - 结构化 JSONL 数据资产 (claims/, cases/, forecasts/, sources/)         |
|  - SHA-256 完整性清单 (manifest.yaml)                                    |
|  - 独立于应用与数据库，支持 ZIP 导出与任意环境无损重建                    |
+-------------------------------------------------------------------------+
```
